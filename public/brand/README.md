# Brand assets (drop-in)

Copy the files from the FOUR brand kit (Google Drive folder) here. The site
picks them up automatically; until then it falls back to a typographic
wordmark so nothing looks broken.

| File | Used for |
|---|---|
| `logo.svg` (or .png) | Nav, popup, footer wordmark |
| `logomark.svg` | Favicons, assistant avatar, small placements |

Keep the exact artwork from the kit. Do not recolor or redraw; the site's
beige/red palette is applied around the logo, never to it.
